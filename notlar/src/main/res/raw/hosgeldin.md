Welcome

Notes are plain Markdown files, and so is this one. Change it or delete it as you like.

> [!tip] Where to start
> Settings → How to write: every format, with examples.

Try a few things:

- [ ] Tap this box to check it
- [ ] Type **bold** on a line; the markers show only while you're on that line
- [ ] Type two square brackets and link a note from the list that opens
- [ ] On the main screen, swipe this note left to trash it (you can restore it from the trash)

Tasks are also collected on the Tasks screen, opened from the bottom bar.

Your notes stay on this phone; the app has no internet access. If you pick a folder in Settings, notes live in that folder, and you can use the same folder with Obsidian or Syncthing.
